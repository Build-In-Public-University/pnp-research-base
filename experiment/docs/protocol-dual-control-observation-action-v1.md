# Dual-control observation/action calibration v1

A hidden object is `fragile` or `sturdy`. The terminal capability is to choose the correct handling action. Immediate handling has wrong-action loss 100. Non-destructive inspection costs 5 and reveals the state. Gentle touch costs 1, reveals the state, but damages a fragile object with modeled cost 10. Correct handling costs 1.

The experiment compares immediate action, inspection, and active probing under rare and common fragile priors. The probe is simultaneously an action and an observation. Values are synthetic modeled units.
