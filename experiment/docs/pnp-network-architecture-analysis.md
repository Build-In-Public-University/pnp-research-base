# Research Seed

The source analysis that motivated this repository is stored at:

`<HOME>/Downloads/pnp-network-architecture-analysis.md`

It is copied into this repository as a working thesis only after review. The operational claim is:

> A result may be locally checkable in polynomial work while the total cost of making it globally trusted, reproducible, transportable, and maintained is dominated by architecture-dependent coordination and validation distance.

## Primary attack

Hold the language/certificate relation fixed. Vary only the containing architecture. Measure local checking operations and lifecycle operations separately. Then test whether architecture variables predict lifecycle cost after local checking work is controlled.

## Kill condition

Stop calling this a distinct architecture-relative phenomenon if lifecycle cost is fully explained by ordinary local runtime, or if the benchmark's network terms are only renamed runtime with no independent observable.
